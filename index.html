Linux Command

pwd= print working directory (laat zien in welke map je werkt)

ls= list files and directories

cd= change directory (naar een map gaan)

man= manual (handleiding)

tree= laat mappenstructuur zien

touch= make new file

mkdir= make new directory

rm= remove file/directory

cp= copy file/directory

mv= move a file/directory

nano= command line text editor

cat= concatenate (laat inhoud zien van een bestand)

less= laat inhoud zien van 1 pagina per keer

head= laat inhoud zien van de bovenkant van een file

tail= laat inhoud zien van de onderkant van een file
